# TFEcat app icons

Use the standard 192px and 512px PNGs with `purpose: "any"`, the corresponding `tfecat-maskable-*` files with `purpose: "maskable"`, and `tfecat-monochrome.svg` with `purpose: "monochrome"` in the future web app manifest. `tfecat.svg` and `tfecat-maskable.svg` are the editable vector sources. The HTML shell already references the Apple touch icon and favicon assets.
